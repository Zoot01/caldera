# @caldera-js/schedule

Caldera scheduling: cron schedules that dispatch jobs, run from a worker, OS cron, Cloudflare cron triggers or Vercel Cron.

Part of [Caldera](https://calderajs.dev), a TypeScript framework for web apps. A new app has it already: `npm create caldera@latest my-app`.

Documentation: https://calderajs.dev/docs/scheduling
