# @caldera-js/cli

The caldera command: the dev server, code generation, generators, migrations, workers, deploy setup and checks, and an MCP server for AI agents.

Part of [Caldera](https://calderajs.dev), a TypeScript framework for web apps. A new app has it already: `npm create caldera@latest my-app`.

Documentation: https://calderajs.dev/docs/cli
