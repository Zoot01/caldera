# create-caldera

Create a [Caldera](https://calderajs.dev) app: a TypeScript framework for web apps, with routing, a database, auth, queues, mail, realtime and more, ready on day one.

```bash
npm create caldera@latest my-app
```

It asks for a starter kit (sign-up, login, settings and a dashboard, or a blank page), teams, the database, where it will run, and the frontend (React pages over Inertia, or Next.js). See [Installation](https://calderajs.dev/docs/installation).
