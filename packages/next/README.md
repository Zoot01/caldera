# @caldera-js/next

Caldera in a Next.js app: the app's routes under /api, submit() and load() for server actions and pages, services in Server Components, a typed client.

Part of [Caldera](https://calderajs.dev), a TypeScript framework for web apps. A new app has it already: `npm create caldera@latest my-app`.

Documentation: https://calderajs.dev/docs/nextjs
