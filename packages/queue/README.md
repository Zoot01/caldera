# @caldera-js/queue

Caldera queues: typed jobs with retries, backoff, timeouts, uniqueness, chains and batches, on the database, Redis (BullMQ), Cloudflare Queues, QStash, or right after the response.

Part of [Caldera](https://calderajs.dev), a TypeScript framework for web apps. A new app has it already: `npm create caldera@latest my-app`.

Documentation: https://calderajs.dev/docs/queues
