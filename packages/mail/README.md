# @caldera-js/mail

Caldera mail: React Email templates with typed props, sent now or queued, over Resend, Postmark, SES, SMTP and more.

Part of [Caldera](https://calderajs.dev), a TypeScript framework for web apps. A new app has it already: `npm create caldera@latest my-app`.

Documentation: https://calderajs.dev/docs/mail
