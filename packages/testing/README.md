# @caldera-js/testing

Caldera testing: boot the app per test file, a migrated database rolled back per test, self-restoring fakes, and an HTTP client with Laravel-style assertions.

Part of [Caldera](https://calderajs.dev), a TypeScript framework for web apps. A new app has it already: `npm create caldera@latest my-app`.

Documentation: https://calderajs.dev/docs/testing
