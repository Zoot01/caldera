# @caldera-js/i18n

Caldera i18n: typed ICU messages, per-request locales, localized validation errors, and only the messages a page needs on the client.

Part of [Caldera](https://calderajs.dev), a TypeScript framework for web apps. A new app has it already: `npm create caldera@latest my-app`.

Documentation: https://calderajs.dev/docs/localization
