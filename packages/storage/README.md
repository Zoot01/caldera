# @caldera-js/storage

Caldera file storage: disks (local, S3, R2), signed links, uploads checked by their bytes, and direct uploads to a bucket.

Part of [Caldera](https://calderajs.dev), a TypeScript framework for web apps. A new app has it already: `npm create caldera@latest my-app`.

Documentation: https://calderajs.dev/docs/storage
