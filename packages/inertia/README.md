# @caldera-js/inertia

Caldera's Inertia adapter: typed pages, shared props, partial reloads and deferred props over Hono, with Vite asset tags.

Part of [Caldera](https://calderajs.dev), a TypeScript framework for web apps. A new app has it already: `npm create caldera@latest my-app`.

Documentation: https://calderajs.dev/docs/pages
