# @caldera-js/broadcast

Caldera realtime broadcasting: typed channels and events over the pusher protocol (Pusher, Soketi, Reverb, a Cloudflare Durable Object, or its own server).

Part of [Caldera](https://calderajs.dev), a TypeScript framework for web apps. A new app has it already: `npm create caldera@latest my-app`.

Documentation: https://calderajs.dev/docs/realtime
